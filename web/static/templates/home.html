Deploy the API — no UI required

The whole scraper is available as a JSON REST API. Set API_ONLY=1 to run a headless backend and integrate scraping into your own product.

Create a scraping job
curl -X POST http://localhost:8080/api/v1/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "name": "dentists-berlin",
    "keywords": ["dentist in Berlin"],
    "lang": "en",
    "depth": 5,
    "max_time": "10m"
  }'
Fetch results as JSON
curl http://localhost:8080/api/v1/jobs/<id>

# or download the CSV
curl -OJ \
  http://localhost:8080/api/v1/jobs/<id>/download
